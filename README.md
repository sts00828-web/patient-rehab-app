# 患者リハビリチェックアプリ

患者が自宅で実施・痛み・メモを記録し、来院時に担当PTと振り返る端末内保存型PWAです。

## 2026-09-18 更新

- 当日記録後に3→7種目などへ変更した場合、セラピスト画面に適用時期と「保存したメニューを今日から反映」を表示。内容・回数・曜日が同じ種目の実施状況と、痛み・メモを保持します。追加・内容変更した種目は未記録にし、変更前の記録はカレンダーとバックアップに残します。

- 日付欄の再修正：表示を通常テキストにし、その上の透明なネイティブ入力で日付選択を維持。ブラウザ固有の日付描画が枠を広げない構造へ変更。次回来院日の解除操作も追加。320px幅・入力の最小幅400pxの模擬条件で検証（iPhone実機は未確認）。

- スマホでは開始日・次回来院日を縦並びにし、日付入力のはみ出しを修正。ヘッダーとモーダル上部にノッチ用の余白を確保し、長い表示名を折り返します。

- スマホ下部のタブに末尾の内容が隠れる問題を修正。本文にタブとホームバーの分の余白を確保し、種目選択の更新ボタンも重ならない配置に変更。

- 五十肩・腰痛・膝OA・上腕骨外側上顆炎（テニス肘）の4領域、各10種目・計40種目の選択式メニュー。
- テニス肘は肘・前腕の軽い運動、ストレッチ、等尺性運動、重りを使う運動、軽い握力練習から選択。手首の筋力種目は段階違いの候補で、重複する負荷をPTが調整します。
- オリジナルAIイラスト40点、拡大表示、日本語の手順、注意点。
- PT画面は目的別に分類し、難易度・種目名・用具で絞り込み可能。非表示になった選択種目も保持し、選択件数に表示します。
- 各種目の目的・用具・選択時の注意を追加。難易度は動作の目安であり、臨床評価尺度ではありません。[種目別の一覧と参考資料](MENU_GUIDE.md)。
- PTが選んだ種目に回数・時間を入力して処方。自動で全種目を患者に処方しません。
- 動画はPTが確認したHTTPS URLを種目ごとに登録可能。外部サイトで開きます。生成動画は含みません。
- 毎日の実施を「できた・一部できた・痛みで休んだ・忘れた」に分けて記録。
- 痛み0と未記録を区別。メモは入力時に保存。
- 日付別の処方履歴と記録時のメニューを保持。記録済みなら通常は翌日から更新し、PTが必要に応じて今日から反映できます。当日も実施曜日に合う種目だけを表示します。
- 開始前・休養日・旧版のメニュー不明日は達成率の分母から除外。
- 別患者の設定は、現在の患者記録を退避して読み込み。同一患者は識別IDで判定。
- 設定QRから氏名・年齢・診断名・PINを除外。フラグメント `#d=` を使用。
- QR生成・読込ライブラリと画像を同梱。初回オンライン読込完了後はオフラインで利用可能。
- カレンダー月末移動、痛みグラフの日付間隔、入力HTMLの扱いも修正。

## 手元で開く

このフォルダで次を実行します（Pythonを使用）。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8765/ を開いてください。ファイルの直接ダブルクリックではQRやPWA機能が正しく動作しない場合があります。

初回は「スタッフ：メニューを設定」または画面上部を2秒長押し。PIN未設定なら空欄で確認します。

1. 患者の呼び名・開始日を設定。
2. 疾患を選び、目的・難易度・検索で候補を絞ります。「イラスト・手順を確認」で図を見て、必要な種目にチェック。回数・時間を入力。
3. 個別の注意点・曜日・動画URLが必要なら編集。
4. 患者の端末へアプリ追加用QRを案内し、アプリ内カメラで設定QRを読み込む。
5. 受信端末で患者の呼び名を設定。日々の記録は来院時のレポートで確認。

## データの扱い

`localStorage.rehab_v2` に設定・記録・カスタムテンプレート・退避記録をまとめて保存します。一度の書き込みで更新し、保存失敗時は直前の状態へ戻します。

旧版の3キーは初回移行時に `rehab_legacy_backup` にそのまま退避し、既存キーも削除しません。当時の処方を復元できない旧記録は、チェック・痛み・メモを保持して「旧記録」と表示します。当時の達成率を推定して表示することはありません。

患者側の「自分の記録をバックアップ」は現在の患者だけを出力します。スタッフの「端末全体をバックアップ」は退避記録・テンプレートも含みます。PINはバックアップやQRで転送せず、端末固有の簡易ロックとして扱います。

PINは認証基盤や暗号化ではありません。QRには運動内容と個別の注意文が含まれます。個別の注意文に氏名などを書かず、本人に直接渡してください。既存の旧形式URLの受信は維持していますが、新しく生成するURLに患者プロフィールは含みません。

## 運動資料と画像

回数・保持時間は一律に決めず、担当PTが評価して設定します。イラストは説明用で、個別の可動域・病期・術後制限を示すものではありません。患者への配布前に担当PTが手順と図を確認してください。

参考資料（2026-09-18確認、画像は転載せず独自生成）：

- [AAOS：Spine Conditioning Program](https://www.orthoinfo.org/recovery/spine-conditioning-program/)
- [Royal Orthopaedic Hospital：Knee OA exercises](https://roh.nhs.uk/services-information/therapy/exercises-for-osteoarthritis-of-the-knee)
- [AAOS：Epicondylitis exercise program](https://orthoinfo.aaos.org/globalassets/pdfs/2022-therapeutic-exercise-program-for-epicondylitis.pdf)

画像：`assets/exercises/*.png`（40点、約64MB）
生成方法：組み込み `image_gen`。プロンプト：`assets/exercises/PROMPTS.json`。

40点とも同じ20代前半の若い男性モデルに統一しました。振り子体操の画像を人物の基準として、顔・髪型・体格・青緑のTシャツ・紺の長ズボン・白〜グレーの靴を合わせています。`illustration-preview.html` で全画像を一覧できます。テニス肘の10点も組み込み `image_gen` で制作し、手首や手が見やすい構図にしています。プロンプトと修正指示を保存しています。

追加種目はOxford University Hospitals、Cambridge University Hospitals、NHSの腰痛・膝OA資料なども参考にしています。各種目の出典は `MENU_GUIDE.md` とアプリ内の手順から開けます。姿勢・支持物などを調整した説明を含みます。既存患者の処方に種目を自動追加することはありません。

## 構成と確認

- `index.html`：画面枠と基本スタイル
- `ui.js`：日付・QR・初回導入などのUI
- `core.js`：入力検証、移行、処方履歴、集計の純粋関数
- `app-v2.js`：画面と保存・患者切り替え
- `exercises.js`：疾患・種目・参考資料
- `sw.js`：アプリ範囲のオフラインキャッシュ

```powershell
node tests/core.test.cjs
node tests/exercises.test.cjs
node tests/browser-smoke.cjs
```

ブラウザテストはWindowsのChromeを非表示の専用プロファイルで起動し、架空データだけを使用します。スクリーンショットは `.test-artifacts/` に保存されます。テスト用プロファイルを通常の患者運用に使用しないでください。

確認済み：データ処理11項目、種目データ・画像・キャッシュ対象3項目、Chromeでの画面・QR・保存・オフライン動作53項目。QRカメラの起動待ちでキャンセルした場合と、権限拒否後の終了処理も模擬カメラで確認しています。スマホ実機のカメラ権限・iPhoneのホーム画面追加・実際の運動指導は、この自動確認の範囲外です。

公開先は https://patient-rehab-app.vercel.app/ です。GitHubの `sts00828-web/patient-rehab-app` の `main` への更新をVercelが自動配信します。公開時は実行用ファイルとassets・vendorを一緒に配置し、更新ごとに `sw.js` のキャッシュバージョンを上げてください。今回のバージョンは `v21` です。更新が表示されないときは、オンラインでアプリを開いた後、一度閉じて開き直してください。端末の記録を残すため、サイトデータの削除は不要です。
